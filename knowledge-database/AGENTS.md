# Knowledge Database Agent Guide

Merkez: [[index]]

Bu klasor Conduut projesinin Obsidian tabanli kalici hafizasidir.

## Kullanim

- Yeni oturumda once `index.md` dosyasindan basla.
- Mimari, feature, karar, debug veya proje durumu degisirse ilgili notu
  guncelle.
- Teknik isimleri oldugu gibi koru; aciklama dili Turkish-first olabilir.
- Obsidian graph icin mevcut not adlarina wikilink kullan.
- ADR'ler `03-decisions/` altinda (2026-06-30 temizliginde yanlis-yazimli
  `03-desicions`'dan rename edildi).

## Dikkat

repo rehberidir. Bu dosya sadece vault icinde calisirken local yonlendirme saglar.
