# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability and do not
include API keys, OAuth secrets, service-account files, access tokens, customer
data, or raw execution payloads in reports.

Use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. Include only the minimum information needed to reproduce the
issue, with secrets and personal data redacted.

If a credential may have been exposed, revoke or rotate it immediately before
continuing the investigation.

## Scope

Conduut is an MVP and portfolio project, not a hosted production service. There
is no public security-support SLA. Reports that help improve the repository are
still welcome through the private channel above.
